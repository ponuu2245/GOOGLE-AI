# 구글 AI 모드 로컬 파일 브릿지

구글 검색 AI 모드가 내 폴더의 파일을 읽고, AI가 제안한 수정을 내가 확인한 뒤 파일에 반영하도록 이어 주는 확장 프로그램 + 로컬 서버입니다. 파일을 지우는 기능은 없습니다.

AI가 쓸 수 있는 도구: `list_dir`(폴더 목록), `read_file`(줄 번호 붙여 읽기), `grep`(여러 파일에서 찾기), `outline`(함수·클래스 위치), `edit_file`(찾아 바꾸기), `write_file`(새 파일·통째 교체).

## 구성
- `server.js` — 로컬 서버 (127.0.0.1:3006). 지정한 폴더 안만 읽음.
- `extension/` — 크롬 확장 프로그램 (manifest.json, background.js, content.js)
- `extension-firefox/` — 파이어폭스용. content.js·background.js는 크롬판과 같고 manifest.json만 다릅니다. 크롬판 js를 고치면 여기에도 복사하세요.
- `build-firefox.bat` — 서명 없는 .xpi 만들기 / `sign-firefox.bat` — 모질라 서명 받기. 결과는 `dist/`

## 1. 서버 실행
Node.js가 필요합니다.
```
node server.js "E:\내\프로젝트\폴더"
```
`✅ 로컬 브릿지 실행` 이 뜨면 정상입니다. 창을 닫으면 서버도 꺼집니다.

## 2. 확장 프로그램 설치 (한 번만)
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더의 `extension` 폴더 선택
4. 코드를 고친 뒤에는 확장 프로그램 카드의 새로고침 버튼을 누르고, 구글 탭도 새로고침

### 파이어폭스 (`extension-firefox` 폴더)
일반 파이어폭스는 모질라 서명이 없는 확장을 영구 설치하지 못합니다. 아래 셋 중 하나를 고르세요.

**A. 모질라 서명 받기 (일반 파이어폭스에 영구 설치, 추천)** — 무료이고, 비공개(unlisted)라 스토어에 올라가지 않습니다.
1. https://addons.mozilla.org/developers/addon/api/key/ 에 파이어폭스 계정으로 로그인 → 개발자 약관 동의 → **새 자격 증명 생성**
2. 나온 **JWT issuer**(user:… 형태)와 **JWT secret**을 메모 (남에게 보여 주지 마세요)
3. `sign-firefox.bat` 더블클릭 → 두 값을 붙여 넣기. 처음에는 `npx`가 web-ext를 내려받습니다. 서명은 보통 몇 분 걸립니다.
4. `dist` 폴더에 생긴 서명된 `.xpi`를 파이어폭스 창에 끌어다 놓고 **추가**
5. 코드를 고쳐 다시 서명할 때는 `extension-firefox\manifest.json`의 `version`을 올려야 합니다(같은 버전은 다시 서명 안 됨).

**B. 서명 없이 영구 설치 (Firefox Developer Edition 또는 Nightly만 가능)**
1. `build-firefox.bat` 실행 → `dist\google-ai-local-bridge.xpi` 생성
2. Developer Edition/Nightly 주소창에 `about:config` → `xpinstall.signatures.required` 를 `false`로
3. `.xpi`를 창에 끌어다 놓고 **추가**

**C. 임시 로드 (재시작하면 사라짐)**
`about:debugging#/runtime/this-firefox` → **임시 부가 기능 로드** → `extension-firefox\manifest.json`

설치 후 패널이 `● 서버 꺼짐`으로 남으면 `about:addons` → 이 확장 → **권한** 탭에서 `127.0.0.1` 과 구글 사이트 접근을 켜 주세요.

## 3. 사용법
1. 구글에서 검색 후 **AI 모드** 탭을 엽니다.
2. 오른쪽 아래 패널이 `● 연결됨` 과 폴더 경로를 보여 주는지 확인합니다.
3. 입력창에 질문을 적고 **1. 지침 프롬프트 넣기** → 질문 앞에 사용 안내가 붙습니다 → 보내기.
4. AI가 `{"mcp_tool": "read_file", ...}` 같은 JSON을 답하면 그 아래 파란 카드가 생깁니다. **▶ 실행 후 결과 넣기**를 누르면 파일 내용이 입력창에 들어가고, 보내면 AI가 이어서 답합니다.
5. **읽기 도구 자동 실행 + 자동 전송**을 켜면 4번을 자동으로 반복합니다.
6. AI가 `edit_file`/`write_file`을 답하면 노란 **수정 카드**에 바뀌는 줄(초록 +, 빨강 -)이 먼저 보입니다. **✅ 적용**을 눌러야 파일이 바뀌고, 원본은 같은 폴더에 `파일이름.bak`으로 남습니다(직전 1개만). 결과는 입력창에 들어가 AI가 이어서 작업합니다.
7. **수정도 묻지 않고 바로 적용**은 확인 없이 쓰므로, 백업을 믿을 수 있을 때만 켜세요.

### 터널로 폴더 보여 주기 (선택)
`node server.js "폴더" --share 60` 으로 켜면 60분 동안 읽기 전용 비밀 주소(`/s/긴토큰/`)가 열립니다. 다른 창에서
```
cloudflared tunnel --url http://127.0.0.1:3006
```
을 실행하고, 나온 `https://….trycloudflare.com` 뒤에 비밀 주소를 붙여 AI 모드에 주면 됩니다. 이 주소를 아는 사람은 누구나 그 폴더를 읽을 수 있고, 구글에도 주소가 전달됩니다. 수정 API는 터널로 들어오지 않습니다.

## 보안
- 서버는 이 컴퓨터(127.0.0.1)에서만 접속되고, 일반 웹사이트는 응답을 읽을 수 없습니다(확장 프로그램만 허용).
- 지정 폴더 밖, 링크로 빠져나가는 경로, `.env`·`*.pem`·`*.key`·SSH 키·`.git`·`.ssh` 는 막습니다.
- **읽은 파일 내용은 구글로 전송됩니다.** 비밀번호·키가 든 폴더는 열지 마세요.
- 자동 실행을 켜면 AI가 요청한 파일을 묻지 않고 구글로 보냅니다. 검색 결과나 파일 안에 도구 호출 JSON이 섞여 있어도 실행될 수 있으니, 믿을 수 있는 폴더에서만 켜세요.
